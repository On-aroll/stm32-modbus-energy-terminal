# 设计说明

## 为什么选择功能码 0x04

采集量是只读测量数据，因此示例采用输入寄存器功能码 `0x04`。部分实际电表会把测量量放在保持寄存器并要求 `0x03`，接入前以设备说明书为准。

## 半双工方向控制

MAX3485 的 DE 和 /RE 并联到 PA8。发送前拉高，`HAL_UART_Transmit` 返回后继续等待 `UART_FLAG_TC`，确认最后一个停止位已移出移位寄存器，再拉低进入接收。若过早切换，末尾 CRC 字节可能被截断；若过晚切换，则可能错过从站快速应答。

## 报文防御性校验

响应必须同时满足：

1. 长度等于 `5 + 2 × 寄存器数`；
2. 从站地址与请求一致；
3. 功能码为 `0x04`；
4. 字节数为 `2 × 寄存器数`；
5. 接收 CRC 与计算 CRC 一致。

任一条件失败都不会更新测量值，并由故障管理器累计失败。

## 当前边界

示例使用阻塞式 UART API，结构直观，适合课程设计与小型采集终端原型。对于更多从站、更短轮询周期或同时执行控制任务的场景，应改用中断/DMA 接收、非阻塞状态机和严格的响应超时管理。
