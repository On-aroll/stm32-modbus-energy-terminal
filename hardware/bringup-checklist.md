# 硬件上电与联调检查表

本表用于把“编译通过”推进到“实物验证”。完成一项后勾选并在测试记录中填写证据。

## 1. 上电前

- [ ] 万用表确认 3.3 V 与 GND 无短路。
- [ ] 确认 RS485 模块为 3.3 V 逻辑，DE 与 /RE 已并联到 PA8。
- [ ] 确认 ST-LINK 使用 SWD 模式，BOOT0 为低电平。
- [ ] 确认电表地址为 1，串口参数为 9600、8 数据位、无校验、1 停止位。
- [ ] 确认寄存器表与 `docs/register-map.md` 一致；不一致时先改映射。

## 2. 最小系统

- [ ] `pio run -t upload` 下载成功。
- [ ] USART1 在 115200 8N1 下打印启动信息。
- [ ] PC13 指示灯在通信失败时翻转。
- [ ] 示波器/逻辑分析仪观察 PA8：发送前拉高，发送完成后拉低。

## 3. 通信链路

- [ ] 捕获请求帧 `01 04 00 00 00 0A 70 0D`。
- [ ] 从站返回 25 字节，地址、功能码和字节数正确。
- [ ] CRC 错误帧被拒绝，失败计数增加。
- [ ] 连续 3 次失败后状态进入 `COMMUNICATION_LOST`。
- [ ] 恢复正常帧后失败计数清零，状态回到 `ONLINE`。

## 4. 数据合理性

- [ ] 三相电压与电表显示误差在预设范围内。
- [ ] 三相电流、功率、功率因数、频率缩放正确。
- [ ] 断开 A/B 后出现超时，重新连接后可自动恢复。
- [ ] 连续运行 30 分钟，无死机、异常复位或明显丢帧。

## 5. 留存证据

- [ ] 保存固件构建日志与 Flash/RAM 占用。
- [ ] 保存串口日志（至少包含正常、断线、恢复三段）。
- [ ] 保存接线全景和 A/B、PA8 局部照片。
- [ ] 填写 `hardware/test-record-template.md`，如实记录未通过项。
