# 接线说明

> 本仓库默认使用 3.3 V MAX3485 模块。接线和上电前请再次确认模块电压与引脚标识；不同厂商的 A/B 标记可能相反。

## STM32 与 MAX3485

| STM32F103C8T6 | MAX3485 | 说明 |
|---|---|---|
| PA2 / USART2_TX | DI | 主控发送 |
| PA3 / USART2_RX | RO | 主控接收 |
| PA8 | DE 与 /RE 并联 | 高电平发送、低电平接收 |
| 3.3 V | VCC | 收发器供电 |
| GND | GND | 逻辑侧共地 |
| - | A、B | 接电表 RS485 A、B |

## 调试串口与下载器

| STM32F103C8T6 | 外设 | 说明 |
|---|---|---|
| PA9 / USART1_TX | USB-TTL RX | 115200 8N1 调试输出 |
| PA10 / USART1_RX | USB-TTL TX | 当前固件未使用接收，可不接 |
| GND | USB-TTL GND | 必须共地 |
| PA13 / SWDIO | ST-LINK SWDIO | SWD 下载 |
| PA14 / SWCLK | ST-LINK SWCLK | SWD 时钟 |
| 3.3 V、GND | ST-LINK 3.3 V、GND | 目标电压参考与地 |

## 总线建议

- 台架仅一个主站和一个从站，使用短双绞线连接 A/B。
- 长线时仅在总线两端各接一个 120 Ω 终端电阻，不要在每个节点都加。
- 若持续超时，先互换 A/B 验证标识差异，再检查波特率、地址、校验位和共地。
- 接真实配电柜或强电测量设备时，应使用隔离型 RS485 与合规电源；本仓库不涉及带电作业设计。
